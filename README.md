# Русский язык · METU v11 — GitHub Pages edition

> **Новая рекомендуемая архитектура:** GitHub Pages запускает статический React/Vite frontend, а Groq вызывается через маленький Cloudflare Worker. FastAPI и Python больше не обязательны для публичного сайта. Конспекты, практика, прогресс, PWA, 3D и TTS работают на клиенте.

## Деплой без Python

Полная пошаговая инструкция находится в [`DEPLOY_GITHUB_PAGES.md`](DEPLOY_GITHUB_PAGES.md).

Ключевая схема:

```text
GitHub Pages (React) -> Cloudflare Worker -> Groq API
           |
           +-> notes-data.json / localStorage / Web Speech API / tutor.glb
```

`GROQ_API_KEY` **нельзя** помещать в frontend или `VITE_*`: он хранится только в Cloudflare Worker secret. GitHub Actions workflow `.github/workflows/deploy-pages.yml` автоматически собирает `frontend/dist`.

Без Worker сайт всё равно работает в локальном режиме по встроенным конспектам.

## Legacy: локальный FastAPI-вариант

Ниже сохранена инструкция старого локального режима. Он больше не нужен для GitHub Pages, но папка `backend` оставлена для совместимости и локальных экспериментов.

Автор в шапке и футере: Измаилов Акбар Парухович. Логотип METU взят из предоставленного изображения и отображается строго круглым.

## Быстрый запуск Windows

1. Полностью распакуйте архив в новую обычную папку rus_v11. Не запускайте файлы из архиватора.
2. Установите Python 3.10+ с опцией Add Python to PATH.
3. Откройте INSTALL_WINDOWS.bat. Для первой установки зависимостей нужен интернет.
4. Откройте START_WINDOWS.bat. Сайт откроется на http://127.0.0.1:8000.
5. Оставьте окно сервера открытым; Ctrl+C останавливает сервер.

Для готовой сборки Node.js не нужен. Если старая версия уже работает на порте 8000, остановите её перед запуском v11.

## Запуск через терминал VS Code

В VS Code откройте папку rus_v11, содержащую run.py. Выберите «Терминал → Новый терминал». В PowerShell из основной папки проекта выполните по очереди:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe run.py
```

Не нужно предварительно заходить в backend. Активация окружения не требуется: команды указывают на его Python напрямую.

Для Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
python run.py
```

При занятом порте: `python run.py --port 8001`.

## AI-диалог

Скопируйте backend/.env.example в backend/.env, добавьте свой GROQ_API_KEY и перезапустите сервер. Установщик Windows создаёт .env автоматически. Модель по умолчанию: openai/gpt-oss-20b. Конспекты, тесты, поиск, заметки и 3D работают без ключа; генерация общих ответов и оценивание свободного ответа требуют ключа и интернета.

Ключ хранится только на сервере. Не вставляйте его во frontend. API выдаёт текст потоково; озвучка обрабатывается отдельными запросами и не задерживает поток ответа.

## Женская нейроозвучка

Основной голос строго женский: ru-RU-SvetlanaNeural. Нажмите «Проверить голос» или «Включить озвучку». Доступны три темпа и настройка громкости. Ответы озвучиваются небольшими фрагментами; рот аватара реагирует на фактическую громкость аудио. Можно отдельно прослушать ответ или текущую тему.

По умолчанию сервер обращается к онлайн-сервису Edge через edge-tts. Нужны интернет, доступ к этому сервису и установленные зависимости. Для него отдельный AI-ключ не требуется, но доступность не гарантируется провайдером.

Для официального Azure Speech вместо Edge заполните AZURE_SPEECH_KEY и AZURE_SPEECH_REGION в backend/.env. Используется тот же женский голос; доступность и тарификация зависят от вашего Azure-аккаунта. Настоящий голосовой клон и обещание полной неотличимости от живого человека не заявляются.

При отказе нейросервиса интерфейс может использовать известный женский русский голос браузера. Мужской голос автоматически не выбирается. Если подходящего женского голоса нет, выводится сообщение о недоступности. Качество резервного голоса зависит от ОС. Голосовой ввод требует Chrome/Edge и HTTPS либо localhost.

## 3D-аватар

Используется детальная модель Female_Adult_01 из Microsoft Rocketbox с лицевыми формами ARKit и viseme. Для веба она преобразована в GLB: выбран 13 наиболее полезных лицевых форм, разреженные morph-данные и WebP-текстуры. Файл около 5.6 MB вместо около 71 MB промежуточного экспорта. Модель, текстуры и декодирование WebP включены локально; скачивание с внешнего CDN при запуске не требуется.

Настроены мягкий ключевой свет, заполняющее освещение, студийный фон, моргание, слабые движения головы и аудиозависимое открытие рта. Это амплитудная синхронизация с несколькими формами рта, а не точное фонемное выравнивание. Есть портретный ракурс, полный рост, ограниченное вращение и экономный режим. Рендер останавливается за пределами видимой области и в скрытой вкладке. На устройствах без WebGL доступны текст и голос.

MIT-лицензия модели сохранена в third-party/ROCKETBOX-LICENSE.md. Модель не воспроизводит внешность автора проекта.

## Новые функции

- Новый графитовый интерфейс с индиго; дополнительные титановые и изумрудные акценты, светлая тема.
- Ctrl+K открывает поиск по названиям и полному содержимому конспектов. «/» переводит фокус в поле вопроса.
- Избранные темы и фильтр закладок.
- Личная заметка к каждой теме с автоматическим сохранением в текущем браузере.
- Режим чтения скрывает боковые панели; содержание темы помогает переходить между разделами.
- Оценка времени чтения и печать/PDF через диалог браузера.
- Учебный таймер на 25 минут с паузой и сбросом. Таймер не сохраняется при закрытии страницы.
- Тесты, карточки, история вопросов и прогресс остаются доступными.
- PWA кеширует сборку и модель для повторного открытия офлайн. Онлайн-чат и нейроголос требуют подключения.

## Редактирование frontend

Нужен Node.js 20.19+ или 22.12+. В отдельном терминале:

```bash
cd frontend
npm ci
npm run dev
```

Оставьте Python-сервер работающим; frontend откроется на http://localhost:5173. После редактирования выполните `npm run build`, чтобы обновить frontend/dist и offline-кеш. Конспекты: backend/notes; для синхронизации встроенной копии выполните `python sync_notes.py`, затем пересоберите frontend и перезапустите сервер.

Для телефона в одной Wi-Fi сети: `python run.py --host 0.0.0.0`, затем адрес `http://IP_компьютера:8000`. Это локальный запуск; публичная эксплуатация требует отдельной авторизации и защиты API.
