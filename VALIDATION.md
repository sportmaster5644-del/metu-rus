# Проверка v11 · 7 октября 2026

## Успешные проверки

- Production build: npm run build, Vite 5.4.21, React 18. Готовая сборка включена в архив.
- API: 8 автоматических тестов на Python 3.12. Проверены все 15 материалов, неизвестные пути, ограничения ввода, локальные ответы и вопрос экзаменатора, AI-поток с историей и понятная ошибка провайдера, выдача frontend и service worker.
- Женский TTS-контракт: ограничения текста и темпа, audio/mpeg, фиксированный ru-RU-SvetlanaNeural, повторное использование кеша, понятный отказ провайдера. Внешний синтез заменён имитацией для автоматического теста.
- Локальная GLB-модель выдаётся сервером. Размер: 5 642 292 байта; текстуры встроены, внешних ссылок нет.
- Headless Chromium: все семь разделов на ширинах 320, 375, 768 и 1024 px; главный экран на 1440 px. Горизонтального переполнения нет.
- Проверены выбор ответа в тесте и объяснение, переворот карточки, переход к конспекту, локальный чат и вопрос экзаменатора.
- Проверены закладка, личная заметка, скрытие и восстановление панелей в режиме чтения, поиск Ctrl+K по полному тексту и старт/пауза таймера.
- Голосовой интерфейс проверен с коротким WAV вместо внешнего синтеза: воспроизведение, изменение громкости, остановка и повторный запуск. При отказе сервиса и наличии только мужского русского голоса озвучка не переключается на него.
- Переключение между портретным ракурсом и полным ростом, отрисовка модели и визуальный осмотр desktop/mobile снимков.
- Service Worker: повторная загрузка при отключённой сети и запуск практики после первого посещения.
- Ошибки JavaScript pageerror: 0 в проверенных сценариях.

- Распакованный архив: 8 тестов API проходят; запуск run.py на отдельном порте, выдача страницы, health API и модели проверены.

## Границы проверки

Запрос к реальному сервису Edge TTS в этой среде не завершился за время ожидания. Живое звучание, естественность голоса, задержка и доступность этого внешнего сервиса здесь не подтверждены. Azure Speech без пользовательского ключа не проверялся. В интерфейсе предусмотрены женский резервный голос и сообщение об отказе; инструкции находятся в README.md.

Настоящего GROQ_API_KEY не было: качество реальных AI-ответов, авторизация и лимиты провайдера не проверены. Поток и обработка ошибок проверены с имитацией ответа API.

Микрофон, голос конкретной ОС, установка PWA, Safari/iOS, реальное слабое устройство, Windows-установщик и доступ через брандмауэр проверяются в целевой среде. Приложение использует человеческий игровой аватар; сходство с конкретным человеком и фотореализм уровня видеозаписи не заявляются. Синхронизация рта амплитудная, без точного выравнивания фонем.

3D-чанк около 898 kB до gzip вызывает предупреждение Vite о размере. Он загружается отдельно; сборка проходит успешно. Проект предназначен для локального запуска; публичный многопользовательский сервис потребует отдельной авторизации и защиты API.
